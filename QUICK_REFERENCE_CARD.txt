ADIM 1: Backing Track Seçimi (15 dakika)
────────────────────────────────────────
1. Pixabay aç: https://pixabay.com/music/
2. Seçtiğin şarkıyla ilgili ara (ör: "rock metal synth")
3. 3-5 şarkı dinle
4. En iyi olanı indir (MP3 320 kbps)
5. Klasör: C:\Users\anile\OneDrive\Desktop\Zuhal-Game-main\games\rhythm-challenge\
   Dosya: smoke-on-water-backing.mp3

ADIM 2: Snare Zamanı Ölçümü (30 dakika)
────────────────────────────────────────
1. Audacity indir: https://www.audacityteam.org/
2. Dosya aç: File → Open → [backing track]
3. View → Spectrogram seçin
4. Snare vuruşunu bul (yüksek frekans çıkıntısı)
5. Timeline'da zamanı oku (ör: 5.32 saniye)
6. Yaz: TOM_HIT_TIME = 5.32

ADIM 3: Kod Güncelleme (5 dakika)
──────────────────────────────────
1. index.html aç (metin editörü)
2. Satır 652: WHITNEY_MP3_URL satırını bul
   Eski: var WHITNEY_MP3_URL = "games/rhythm-challenge/whitney-halftime.mp3";
   Yeni: var WHITNEY_MP3_URL = "games/rhythm-challenge/smoke-on-water-backing.mp3";

3. Satır 391: TOM_HIT_TIME satırını bul
   Eski: var TOM_HIT_TIME = 12.18;
   Yeni: var TOM_HIT_TIME = 5.32; // Smoke on the Water snare zamanı

ADIM 4: Canlı Test (60 dakika)
